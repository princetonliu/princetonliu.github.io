Machine Learning for Families of Fluid Operators
Princeton Liu, Joseph Wang, Frank Cole, Adrien Weihs, Hayden Schaeffer
Computational and Applied Math REU @ UCLA, 2026
project slides

Proposed a lifted Multi-FNO to predict fluid flows across viscosities ~4,600x faster than numerical solvers. Cut L2 error from 16.8% → 9.0% by fusing branches in latent space. Diagnosed branch collapse in multi-branch FNOs and sped up dataset generation by 3.2x with a parallel pseudo-spectral solver.

Context-Aware LLM Content Moderation
Sherine Chally, Arjen Singh, Princeton Liu, Jason Cheng, Brian Yang
project report / project repository

Built a dual-model system pairing a chatbot with an LLM supervisor (Llama 3) that screens rolling conversation history for harmful escalation. Raised early escalation detection from 24% → 81% over the top-F1 baseline (HateBERT) using an 8B supervisor.

Tokenization Schemes for Autoregressive PDE Transformers
PyTorch, Transformers
project report

Compared five tokenizers for autoregressive Lorenz system prediction and found a 19x gap in per-step loss across models. Showed the top per-token-accuracy scheme drifted off the Lorenz attractor with 10x worse rollout error.

More Batches is All You Need (Neural Signal Speech Decoder)
GRUs, Attention
project manuscript, results, and code

Designed and evaluated GRU-based neural decoders with residual attention, achieving 25% error reduction on neural signal decoding task. Conducted ablations and performance analysis on attention mechanisms and sequence modeling choices.

Exact Dynamic Programming vs. Deep RL on Finite-Horizon MDPs
PyTorch, Double DQN
project report

Modeled optimal execution on a prediction market as a finite-horizon MDP over 6,331 real episodes, solved exactly by backward induction. Trained a Double DQN with experience replay, target networks, and reward shaping on feature-engineered states.
